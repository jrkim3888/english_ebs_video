# 귀트영 영상 제작

월호 표지와 영어 원고를 입력받아 제목 낭독과 본문 3회 반복으로 구성하는 영어 듣기 영상을 제작한다.

- [공통 영상 제작 지침](영상_제작_지침.md): 입력 자료, 음성 선택, 본문 이미지, 자막, 썸네일, 환경 설정과 검수 기준.
- [2026년 11월 2일 제작 예시](2026-11-02_귀트영_영상_생성_지침.md): 싱가포르 원고의 해석과 5개 장면별 이미지 생성 프롬프트.
- [확정 썸네일 참고 이미지](docs/assets/thumbnail-bilingual-approved.png): 큰 영어 제목과 작은 한글 제목을 함께 배치하는 기준 시안.
- [확정 본문 참고 화면](docs/assets/video-style-approved.jpg): 작은 한 줄 제목, 제목 배경 불투명도 65퍼센트와 자막 배경 약 55퍼센트를 적용한 화면.
- [최신 영상 2026년 11월 5일](examples/2026-11-05/README.md): 미국 여자·1배속 영상, 썸네일, 전체 제작자료 ZIP 다운로드. 이전 샘플 영상과 영상이 포함된 ZIP은 현재 브랜치에서 제거했다.

음성은 **미국 남자 / 미국 여자 / 영국 남자 / 영국 여자** 중 한글로 지정한다. 지정하지 않으면 **미국 여자**, 속도는 입력 없이 **1배속 고정**이다.

```text
첨부한 월호 표지와 원고로 영상 제작해줘.
음성: 미국 남자
```

본문은 **영어 자막 → 한국어 해석 → 제목만** 순서로 반복한다. 썸네일은 영어 원제를 크게, 한글 제목을 작게 표시하며 ‘영어 듣기’, ‘3회 반복’ 문구는 넣지 않는다.
