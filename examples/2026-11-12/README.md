요청한 **미국 여자** 음성에 **1배속**을 적용했다. 영상은 약 **3분 44초**, **1920×1080**, 30fps다. 제목을 한 번 낭독하고 본문 전체를 영어 자막, 한국어 해석, 제목만 표시하는 순서로 세 번 반복한다.

라일락·민트·흰색·짙은 보라의 3D 기술 모형 이미지 5장을 같은 순서와 시점에 재사용한다. 최근 3편과 화풍·색감·구도를 바꾸고 인물 없는 전경·탑뷰·클로즈업을 구성했다. 상단 제목은 작은 한 줄, 제목 배경 불투명도는 65퍼센트, 자막 배경은 약 55퍼센트다. 전체 디코딩과 각 회차의 대표 화면, 원문 9문장과 자막 21개 구간의 일치 및 실제 낭독 시점을 확인했다. 전체 음성 수동 청취 검수는 하지 않았다.

전체 제작자료에는 최종 영상과 썸네일, 표지와 이미지, 원고와 해석, 음성과 자막 시점, 생성 프롬프트, 제작 코드와 지침을 포함한다. 사용자 요청에 따라 이전 11월 11일 샘플 영상과 해당 제작자료 ZIP은 현재 브랜치에서 제거했다.
