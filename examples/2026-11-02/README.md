# 2026년 11월 2일 귀트영 제작 예시

2026년 11월호의 「Singapore Rolls Out Incentives to Confront Demographic Decline」 원고로 제작했다. 미국 남자 음성, 1배속, 약 3분 57초, 1920×1080 영상이다.

- [완성 영상 다운로드](2026-11-02-singapore-us-male.mp4)
- [확정 썸네일 다운로드](thumbnail-bilingual.png)
- [전체 제작자료 ZIP 다운로드](2026-11-02-production.zip)

영상과 ZIP은 Git LFS 파일이다. GitHub 파일 페이지에서 **Download raw file**을 누르면 실제 파일을 내려받을 수 있다. Git으로 받았다면 Git LFS를 설치하고 `git lfs pull`을 실행한다.

본문 이미지 5장과 동일한 영어 음성을 세 회차에 재사용한다. 첫 번째는 영어 자막, 두 번째는 한국어 해석, 세 번째는 영어 제목만 표시한다. 전체 디코딩과 각 회차의 자막 화면을 확인했으며, 전체 음성 수동 청취 검수는 하지 않았다.

확정 썸네일은 영어 원제를 크게, 한글 제목을 작게 표시하고 ‘영어 듣기’와 ‘3회 반복’ 문구는 넣지 않는다. 아래 이미지는 확정한 디자인 시안이며, 재제작 시 [공통 지침](../../영상_제작_지침.md)의 최종 출력 크기인 1280×720을 적용한다.

![영어 제목과 작은 한글 제목을 함께 표시한 확정 썸네일](thumbnail-bilingual.png)

전체 제작자료에는 원본 영어 원고, 한국어 해석과 자막, 이미지 5장, 표지, 제목·본문 음성, 실제 시점 정보, 제작 코드, 최신 지침, 최종 영상과 썸네일 시안을 포함한다. 중간 인코딩 영상과 재생성 가능한 프레임은 제외했다.
